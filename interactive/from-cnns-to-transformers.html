From CNNs to Transformers

A transformer is assembled from parts you already know: shared weights from convolutions, a running summary from recurrent networks, residual connections and normalization from ResNets. One new part ties them together. Attention lets every token decide which other tokens to read. This page builds the model in eleven steps, timed for one 75-minute class.

Notation. A sentence is N tokens, each a vector of D numbers. Here X is N × D with one token per row, as PyTorch stores it. Prince stores tokens as columns (D × N), so his equations are the transposes of the ones on this page.     0:00

    Step 1 · 5 min · Glassner pp. 566–571 · UDL §12.1

    What a sentence asks of a network

    Text arrives as a sequence of tokens, and each token is looked up in a table to become a vector of D numbers. The whole sentence is an N × D matrix. Whatever layer we design has to meet three demands.

    1. Any length. A sentence may have 5 tokens or 5,000. The number of parameters cannot depend on N.
    2. Shared weights. “dog” means the same thing at position 2 and at position 200. The layer should not relearn it for each position.
    3. Long-range links that depend on the words. Read the two sentences below. Understanding “hungry” means connecting it to “dog”, six tokens back. Change one word to “round” and the connection has to move to “ball”.

    A fully connected layer fails the first two demands at once. With N = 1,000 tokens and D = 1,024 the input holds 1,024,000 numbers. One fully connected layer of the same width needs about 1012 weights, and it only accepts sentences of exactly 1,000 tokens. You solved this problem for images in Week 10. Start there.

    Step 2 · 8 min · from Week 10 · UDL §10.2

    Convolution: shared weights, short reach

    A 1D convolution slides one small kernel along the sequence. The same weights are used at every position, so the layer works for any N, and every position can be computed at the same time. Demands 1 and 2 are met. The trouble is reach: each output sees only k neighbours.

    Receptive field of one unit 17 tokens, stride 1

    Keep

    One set of weights reused at every position. All positions computed in parallel.

    Fix

    Distant words need many layers to meet. The kernel weights are frozen after training, so every sentence gets the same mixing pattern.

    Hold on to one formula. A convolution output is a weighted sum of neighbours, hi = Σj wj−i xj, where the weight depends only on the offset j − i. Attention will keep the weighted sum and change where the weights come from.

    Step 3 · 8 min · Glassner p. 565 and Ch. 19 · not in UDL

    Recurrence: unlimited reach, one step at a time

    A recurrent network reads the tokens in order and keeps a running summary, the hidden state: ht = tanh(Wh ht−1 + Wx xt). The same two matrices are used at every step, so any length works, and in principle ht can remember anything that came before.

    Two costs follow from that chain. First, step t must wait for step t − 1, so the positions cannot be computed in parallel. Second, a signal passing through T steps is multiplied T times. In the simplest scalar model, ht = γ ht−1 + xt, the gradient from step 20 back to step t is exactly γ20−t.

    How much of each token survives to step 20 scalar model, log scale

    LSTM and GRU cells soften this with a gated additive path, ct = ft ct−1 + it gt. It is the same idea as the residual connection from Week 10: give the signal a route that is added, not multiplied through a nonlinearity. It helps, but the path between two words is still as long as the distance between them.

    Keep

    Every token can, in principle, use everything before it. Weights are shared over time.

    Fix

    The path between two tokens grows with their distance. Steps run one after another. The whole past is squeezed into one vector.

    Step 4 · 8 min · Glassner pp. 574–575

    Attention: look it up, don’t carry it

    Compare how the three designs move information from token 1 to token 9.

    The idea came from translation. In 2014 an encoder RNN compressed the source sentence into one vector and a decoder RNN unpacked it. Bahdanau, Cho and Bengio kept all the encoder states instead. At each output word the decoder scores every encoder state against what it currently needs and takes a weighted average. In 2017 Vaswani and colleagues removed the recurrence and kept only that lookup.

    Think of a Python dictionary. A query is compared with every key, and the value stored under the matching key is returned. Attention is the soft version: every key matches to a degree, measured by a dot product. A softmax turns the scores into weights, and the result is the weighted average of all the values.

    Glassner tells the same story with a paint store. Your request is the query, the name on each can is a key, and the paint inside is the value: the better a name matches the request, the more of that paint goes into the mix.

    Soft lookup with four keys drag the query, or use the slider

    Scores are β q·k. At β = 0 every key gets the same weight and the output is the plain average, 25. At β = 12 the best match takes nearly everything, which is an ordinary dictionary. Raising β is the same as making the query vector longer.

    Step 5 · 14 min · Glassner pp. 576–579 · UDL §12.2

    Self-attention, computed by hand

    In self-attention the sentence looks itself up. Every token plays all three roles, through three linear maps of the same X: a query (what am I looking for?), a key (what do I offer for matching?), and a value (what do I hand over if read?). Set it beside the convolution from Step 2:

    • Convolution: hi = Σj near i wj−i xj. Weights fixed by offset.
    • Self-attention: hi = Σall j a(xi, xj) vj. Weights computed from the two tokens.

    Step through the computation on the running sentence. Pick a query token, then swap the last word and watch the weights move.

    Six steps on nine tokens D = 4, weights set by hand

    Last word
    Query token

    All six steps fit in one line:

    Sa[X]=softmax(QKTD)V,Q=XWq,K=XWk,V=XWv
    • Any length, shared weights. The only parameters are Wq, Wk, Wv, each D × D. Nothing depends on N.
    • One step between any two tokens, and no loop over positions: three matrix products and a softmax.
    • The price. The attention matrix is N × N. Time and memory grow with the square of the sequence length.

    Try “it” as the query. “dog” and “ball” receive exactly the same weight. One layer cannot decide, because the query of “it” is computed from “it” alone. In a second layer “it” can read from “hungry”, which by then carries “dog”. Stacking layers composes lookups, the same way stacking convolutions composed receptive fields.

    The same six steps in PyTorch

    import math, torch, torch.nn as nn, torch.nn.functional as F

class SelfAttention(nn.Module):
    def __init__(self, D):
        super().__init__()
        self.q = nn.Linear(D, D, bias=False)
        self.k = nn.Linear(D, D, bias=False)
        self.v = nn.Linear(D, D, bias=False)

    def forward(self, X):                          # X: (N, D)
        Q, K, V = self.q(X), self.k(X), self.v(X)  # step 2
        S = Q @ K.T / math.sqrt(X.shape[-1])       # steps 3-4: (N, N)
        A = F.softmax(S, dim=-1)                   # step 5: rows sum to 1
        return A @ V                               # step 6: (N, D)

    Step 6 · 4 min · Glassner p. 577 · UDL §12.3.2

    Why divide by √D

    If the entries of a query and a key are independent with unit variance, their dot product is a sum of D terms and has variance D. At D = 1,024 a typical score is around ±32. Softmax of numbers that large is nearly one-hot, and a one-hot softmax has almost zero gradient. Dividing by √D brings the scores back to unit scale whatever the width.

    Step 7 · 7 min · Glassner pp. 584–585 · UDL §12.3.1

    Putting word order back

    Look again at the formula in Step 5. Nothing in it mentions position. Shuffle the rows of X and the rows of the output are shuffled the same way, with every number unchanged. A convolution was equivariant to translation; self-attention is equivariant to every permutation. To this layer “dog ignored ball” and “ball ignored dog” are the same bag of words.

    Shuffle the sentence each card shows a token and its output row

    The fix is to tell each token where it is before the first layer: X ← X + P, where row p of P encodes position p. The original transformer used sinusoids at geometrically spaced frequencies:

    Pp,2i=sin(pωi),Pp,2i+1=cos(pωi),ωi=10000−2i/D

    Each pair of dimensions is a clock hand turning at its own speed. Shifting by k positions turns every hand by a fixed angle, so Pp+k is a rotation of Pp. A rotation is a linear map, so Wq can learn it. That lets a head ask for “the token k places away”.

    Sinusoidal encoding 32 positions, D = 16

    Other choices exist. BERT and GPT-2 learn a table with one row per position. Recent language models rotate the queries and keys directly (RoPE), which you will meet in the language-model sessions.

    Step 8 · 5 min · Glassner pp. 580–581 · UDL §12.3.3

    Several heads, several questions

    One softmax row is one distribution, so with a single set of weights a token asks one question. Words relate in several ways at once: a verb wants its subject, its object, and the word just before it. Multi-head attention runs H small attentions in parallel. Each head has its own Wq, Wk, Wv of width D/H. Their outputs are concatenated and mixed by one more matrix Wo. The total cost is about the same as one full-width head.

    Two heads on the same sentence rows are queries, columns are the tokens read

    Head A is the content head from Step 5. Head B ignores the words: its Wq rotates each position encoding one place back, so every token reads the token before it. Head B is one tap of a convolution kernel. With k such heads at k offsets, an attention layer can reproduce a size-k convolution (Cordonnier et al., 2020). Convolution is a special case the model can learn when the data call for it.

    Step 9 · 7 min · Glassner pp. 582–587 · UDL §12.4

    The transformer block

    Attention alone is a weighted average: almost linear, and in Step 5 “hungry” came out mostly as “dog”, having lost itself. The block wraps attention in three parts you have used before.

    Week 10 · ResNetsResidual connections
    Each sublayer computes a correction that is added to its input. The token keeps its own identity, and gradients have a short path through the stack.
    Weeks 3–4 · shallow networksThe MLP
    A one-hidden-layer network applied to every token separately with the same weights. It is a 1×1 convolution over the sequence, and it supplies the nonlinearity. With hidden width 4D it holds 8D² weights against 4D² in attention: two thirds of the block.
    Week 10 · BatchNorm’s cousinLayer normalization
    Each token’s D numbers are shifted and scaled to zero mean and unit variance. No statistic crosses tokens or examples, so it behaves the same for any batch size or sentence length.
    Step 7Position, once
    The positional encoding is added to X before the first block. The residual path carries it upward to every later block.

    Which numbers share one mean and variance rows are tokens, columns are features

    class Block(nn.Module):
    def __init__(self, D, H):
        super().__init__()
        self.attn = nn.MultiheadAttention(D, H, batch_first=True)
        self.mlp  = nn.Sequential(nn.Linear(D, 4 * D), nn.GELU(), nn.Linear(4 * D, D))
        self.n1, self.n2 = nn.LayerNorm(D), nn.LayerNorm(D)

    def forward(self, X):                          # X: (B, N, D)
        X = self.n1(X + self.attn(X, X, X, need_weights=False)[0])
        return self.n2(X + self.mlp(X))

    A transformer is this block repeated. The 2017 base model stacks 6 blocks with D = 512 (65 million parameters). BERT-base stacks 12 with D = 768 (110 million).

    Step 10 · 6 min · Glassner pp. 588–596 · UDL §12.6–12.10

    Three ways to use the block

    The same block gives three model families. The difference is which tokens each position is allowed to read, set by a mask applied to the scores before the softmax.

    FamilyEach token readsTrained toUsed forExample

    The encoder–decoder link is called cross-attention: queries come from the decoder, keys and values from the encoder. It is the translation lookup from Step 4, unchanged.

    Back to images

    A Vision Transformer cuts a 224 × 224 image into 16 × 16 patches, giving 14 × 14 = 196 tokens, and runs an encoder on them. The patch embedding is a convolution with kernel 16 and stride 16. After that there is no locality built in: the model must learn from data what a convolution assumed from the start, so it needs more data, and wins when it has enough.

    Check your understanding

    You double the sequence length. What happens to the cost of a self-attention layer, and of a recurrent layer?

    Self-attention costs four times as much, because the attention matrix is N × N. The recurrent layer costs twice as much, but its 2N steps must still run one after another.

    You remove the positional encoding from an encoder and classify by averaging the output tokens. What can the model no longer tell apart?

    Any two sentences made of the same words in a different order. Permuting the input permutes the outputs, and the average does not change. The model is a bag-of-words classifier.

    With D = 1,024 and unit-variance entries, how large is a typical unscaled score, and what does the softmax do with it?

    The standard deviation is √1,024 = 32. Differences of that size make the softmax nearly one-hot, where its derivative is close to zero, so the weights producing the queries and keys stop learning.

    In one block, which parts move information between tokens?

    Only the attention sublayer. The MLP, both LayerNorms and both residual additions act on each token separately.

    A decoder is trained with a causal mask on a sentence of N tokens. How many next-token predictions does one forward pass give?

    One per position. Because no position can read ahead, all the predictions are computed in a single parallel pass. At generation time the model has to produce one token, append it, and run again.

    Why does “it” fail to choose between “dog” and “ball” in one layer, and what changes with two?

    In layer 1 the query of “it” is a function of the embedding of “it” only, and both nouns match it equally. After layer 1, “hungry” carries information about “dog”. In layer 2 “it” can attend to “hungry” and receive that information.
