# House style for IMSE 774 lecture notes

`notes/01-introduction.qmd` is the reference implementation. When in doubt, open
it and match it.

## Repository layout

| Path | Purpose |
|:--|:--|
| `notes/NN-slug.qmd` | One note per week, scaffolded by `scripts/new_note.py` |
| `notes/images/chNN/` | Figures reproduced from the textbook |
| `notes/_metadata.yml` | Shared format settings; sets `crossref` prefixes and author |
| `_quarto.yml` | Sidebar order, theme, bibliography, PDF preamble |
| `references.bib` | Citation keys — `prince2024`, `goodfellow2016`, and others |
| `schedule.qmd` | Week/date/reading/assignment table the note header must agree with |
| `assets/css/styles.css` | Defines `.lecture-meta`; everything else is stock Quarto |

Do not add a level-1 `#` heading to a note body. `_quarto.yml` sets
`shift-heading-level-by: -1` for PDF, so `##` is the top level and a `#` would
be promoted into the document title.

## Section reference lines

Every `##` and `###` content section opens with one italic line naming the
source, on its own line directly under the heading:

```markdown
## Unsupervised Learning

*Prince §1.2, pp. 7–11.*
```

Include the figure page when the section carries a figure:
`*Prince §1.1.1, p. 2; figure on p. 3.*`

Sections are auto-numbered (`number-sections: true`), so never number headings
by hand.

## Figures

**Reproduced from the textbook** — markdown image, caption is the citation
only, because the book's own caption is already baked into the screenshot:

```markdown
![Prince (2024), figure 1.3, p. 4.](images/ch01/fig-1-03-child-height-model.png){#fig-udl-1-3 width=80%}
```

Label scheme `#fig-udl-C-N`. Widths: 76–85% for landscape figures, 62–70% for
tall or full-page ones. If a screenshot arrived without its caption, write the
book's caption out in full, including the original credits it names.

**Generated by code** — a labelled cell with `fig-cap`:

```python
#| label: fig-relu
#| fig-cap: "The ReLU clips negative inputs to zero. The kink at the origin is the entire source of a ReLU network's nonlinearity."
```

Escape backslashes inside `fig-cap` (`$\\phi_0$`), and reference figures as
`@fig-relu`. Captions should say what the reader is meant to notice, not just
name the contents.

## Equations

Label the ones the text refers back to, and say which book equation they are:

```markdown
$$
y = f[x, \boldsymbol{\phi}] = \phi_0 + \phi_1 x.
$$ {#eq-linear}
```

Follow Prince's notation: square brackets `f[\cdot]` for function application,
parentheses for grouping, bold lowercase vectors, bold uppercase matrices.
Add a `callout-note` titled "Notation" the first time a convention appears.

## Cross-reference gotcha

A letter directly after a reference is swallowed into the label and breaks the
link. Bold the panel letter to terminate it:

- Wrong: `@fig-udl-1-2d` → `WARNING: Unable to resolve crossref`
- Right: `@fig-udl-1-2**d**`

## Tables

Always give a caption line and column widths:

```markdown
: The five concerns of Prince §1.4, pp. 13–14. {tbl-colwidths="[16,64,20]"}
```

Keep cells short — one clause. Explanation belongs in the surrounding prose.

## Callouts

| Type | Use for |
|:--|:--|
| `callout-note` | Notation, scope, an aside that is not load-bearing |
| `callout-tip` | Study advice, how to read something |
| `callout-important` | A caveat the reader will otherwise get wrong |
| `callout-warning` | Ethical or safety framing |
| `callout-note appearance="minimal"` | Preamble to the exercise list |

## Exercises

Numbered bold entries. Cite the source of each:

```markdown
**3. (UDL 3.10)** Consider a network with one input, one output, and $D$ hidden units...

**9. Computational.** Re-run the bandit experiment in @fig-bandit with...
```

Mark starred UDL problems `(UDL 2.3\*)` — those have published answers. Aim for
roughly eight to ten: a few conceptual, the chapter's own problems, and two
computational ones that extend code already on the page.

## Textbook Reference Map

Closes every note. A table mapping each of the note's sections to its Prince
section, page range, and figures, then a sentence mapping the note's equation
labels onto the book's equation numbers, then the credits callout:

```markdown
::: {.callout-note appearance="simple"}
## Figure credits
Figures 3.1–3.14 are reproduced unaltered from Prince, *Understanding Deep
Learning* (MIT Press, 2024), which is distributed under a Creative Commons
CC-BY-NC-ND license, and are used here for non-commercial classroom
instruction. Original sources credited within the figures: ... All other
figures on this page are generated by the code shown.
:::
```

List the third-party credits that appear inside the reproduced figures
themselves — the book names them, so the note must too.

## Prose conventions

- Address the reader as "we" for shared derivation, "you" in objectives and exercises.
- **Bold** a term at the point it is defined, once.
- Blockquote Prince only when the exact wording earns it, and attribute:
  `> --- Prince, p. 5`
- Prefer complete sentences to bullet fragments in explanatory passages; bullets
  are for genuine lists.
- Close each note with a **Next:** sentence pointing at the following chapter.
- Colours are fixed in the setup cell: `NDSU_GREEN`, `NDSU_GOLD`, `ACCENT`. Use
  them instead of matplotlib defaults.
